# Capital Collide AI
## Autonomous Business & Technology Documentary Production System

Capital Collide AI is a fully autonomous system that discovers topics, researches evidence, writes scripts, generates narration and visuals, and publishes long-form and vertical content to YouTube and Instagram.

### Core Philosophy
- **Cloud-First:** Production runs on remote workers, not on the owner's Mac.
- **Zero-Cost:** Uses free-tier APIs and open-source models (Piper, Gemini Free).
- **Autonomous:** Runs on a daily cycle without manual intervention.
- **Evidence-Backed:** Every claim is verified through a fact-checking gate.

### Deployment
1. Clone repository.
2. Run `./scripts/setup.sh`.
3. Configure `.env` with provided API keys.
4. Launch daily orchestrator.
